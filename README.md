# 拾光 · 个人知识收藏库

把散落在不同平台的收藏放到一起，按标题、标签和笔记找回它们。

**[打开网站](https://wuhy80.github.io/shiguang/)**

## 网页版

网站通过 GitHub Pages 发布，电脑和手机浏览器均可打开。

**支持 GitHub 登录与 Supabase 跨设备自动同步。** 在网站和电脑扩展中用同一账号登录一次，电脑按住空格再按 S 打开收藏窗口，保存后进入私有知识库，查看时再打开网站。无需每次填写表单或导入文件。离线时先保存本机：网站打开后同步、扩展在浏览器运行时每分钟重试。未登录仍可本地使用。

真实收藏存放在 Supabase，行级权限只允许所属账号访问；公开 GitHub 仓库仅包含代码、公开客户端 key 和示例，不包含真实收藏、登录令牌或管理密钥。

清除设备数据或卸载前请确认同步完成，或导出备份。

## 主要功能

- 标题 / 标签 / 笔记 / 作者搜索，多个搜索词用空格分隔、同时匹配。
- 平台、标签、阅读状态和内容类型筛选；网格与列表视图。
- 特别关注、待阅读、标为已读、随机回看、笔记和标签编辑。
- JSON、CSV、HTML 浏览器书签导入；导入前检查勾选；URL 自动去重。
- AI 增强（可选）：新收藏自动生成一句话摘要与 ✦ 建议标签，支持按意思查找的语义搜索和每周 AI 回顾；需登录并配置智谱 GLM，未配置时自动停用。

首次进入显示醒目标注的示例库；点击“进入我的空白知识库”，或添加 / 导入真实内容即可退出示例。

## AI 摘要与语义搜索

登录后，网站会为新收藏自动生成一句话摘要与建议标签（卡片上以 ✦ 标注），点击 ✦ 标签即可采纳为分类；详情弹窗可一键采纳或重新生成。搜索框旁的「✦ 语义」开关提供语义搜索：按意思而不是关键词查找，例如搜“讲精力管理的文章”能命中对应收藏；语义模式下仍可叠加平台、标签、阅读状态筛选。侧边栏的「✦ 本周回顾」把近 7 天收藏与待阅读聚合成一份 AI 导读。已有收藏可在「备份与数据管理」中批量补齐摘要或重建语义索引，按钮均带进度与停止。

隐私与数据：生成摘要、标签时会把该收藏的标题、标签、笔记摘录与平台名发送给智谱 GLM（bigmodel.cn）接口；语义搜索会把搜索词发送给同一接口用于向量化。语义向量只保存在本机浏览器，不上传、不随备份导出；摘要与标签保存在你自己的 Supabase 数据库中，与收藏一起同步。登录前或未配置时以上功能全部自动停用，网站行为与现在完全一致；「清除 AI 数据」可移除本机向量与本条 AI 字段。

启用步骤（一次性）：

1. 在 [open.bigmodel.cn](https://open.bigmodel.cn) 注册并创建 API Key。摘要默认使用 glm-4-flash（免费），向量使用 embedding-3（约 0.5 元 / 百万 token），个人库全年成本通常在几元以内。
2. 配置密钥：`supabase secrets set GLM_API_KEY=你的key`，可选 `supabase secrets set GLM_MODEL=其他模型名`。
3. 部署两个边缘函数：`supabase functions deploy ai-enrich`、`supabase functions deploy ai-embed`。
4. 打开网站并登录，进入「备份与数据管理」点击「检测 AI 配置」。

两个函数与 link-preview 采用相同的防护：要求用户 JWT、来源白名单、逐用户限流、请求体上限；GLM 密钥只存在 Supabase 服务端环境变量中，不进入代码仓库、网页或扩展。

## 日常快捷收藏

电脑：安装 / 更新「拾光 · 一键收藏」扩展后，刷新原网页，在视频或文章页面**按住空格，再按 S**，或在网页右键选择「收藏到拾光…」。弹出的独立收藏窗口可选填「分类 / 标签」和「为什么收藏它」；留空也可以保存。多个分类用逗号分隔，在网站中以标签显示并可筛选、搜索。选中的网页文字会作为摘录保存。点击「保存收藏」或 Ctrl + Enter 后先保存到本机扩展，再自动同步；Esc 取消不会新增收藏。

空格 + S 仅在普通 HTTP / HTTPS 网页内生效，在输入框、文本编辑区中不触发。普通空格滚动保留。扩展安装或更新后，已经打开的来源网页需要刷新一次。备用快捷键 Alt + Shift + S 由浏览器扩展命令提供，也可在 Chrome 的 chrome://extensions/shortcuts 中调整。浏览器设置页、扩展商店等受保护页面不能采集。Chrome 原生分享菜单没有接入此扩展，使用快捷键或网页右键入口。

网站里的收藏封面和标题直接在新标签页打开原内容；「编辑」修改标题、分类和收藏原因；「详情」查看完整笔记、阅读状态和删除入口。列表视图同样支持这些操作。重复链接保留已有笔记和状态。扩展排队数据只有在网站成功写入后才移除。

**登录后跨设备同步。** 网站继续部署于 GitHub Pages，私有数据由 Supabase 保存。扩展右键 →「选项」中登录，网站右上角「登录同步」中登录。

## 如何带入旧收藏

电脑上打开网站的“导入与采集”，下载并解压采集扩展。在 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions 开启开发者模式，选择“加载已解压的扩展程序”。

1. 在扩展图标上点右键 →「选项」，打开旧收藏批量采集工具。然后在原平台登录，打开收藏 / 书签 / 稍后观看页面。
2. 滚动加载需要的条目，点击扩展“采集当前页面”。
3. 检查勾选链接，导出 JSON。
4. 回到拾光导入文件，重复链接会跳过，并保留已有笔记和状态。

扩展使用 activeTab、scripting、storage、alarms、contextMenus 权限，仅对 wuhy80.github.io 与拾光 Supabase 项目请求常驻访问；快捷键脚本在普通 HTTP / HTTPS 网页监听空格 + S，不读取密码或输入框内容；知识库归档脚本只匹配 /shiguang/ 路径。扩展只在你主动触发收藏时读取来源网页标题、链接和选中文字，收藏先保存到扩展存储，网站打开后自动归档；批量模式读取页面 DOM 中已加载的链接，不读取密码或 Cookie。动态 / 虚拟列表以及网页结构变化可能导致漏采，可分批采集或手动补充。未使用你的真实账号验证所有平台。浏览器采集扩展用于桌面 Chrome / Edge。

## 来源与兼容性

提供小红书、B 站、知乎、LINUX DO、抖音、YouTube、GitHub、自定义“炉子”和其他网站的分类。平台的收藏夹、帖子书签、稍后观看、喜欢、Stars 可作为候选收集来源，由你自行选择并检查后导入；这些分类不代表已连接账号。

“炉子”的具体应用尚未确认，作为自定义来源；添加或导入时可手动指定。YouTube 稍后观看不支持常规播放列表列表 API 读取，见[官方说明](https://developers.google.com/youtube/v3/docs/playlists/list)。

支持带 items 数组的 JSON、HTML 书签和 CSV。CSV 表头使用 title,url,tags,notes 或 标题,链接,标签,笔记；也支持 YouTube Takeout 的 Video Id 表头。其他平台专有导出格式不保证兼容。搜索覆盖已保存的元数据和笔记，不抓取网页正文或下载视频。

## 开发与发布

本地运行：安装 Node.js，执行 npm start，打开 http://127.0.0.1:4178 。也可以双击 start.bat。Supabase 官方客户端已打包到 dist/supabase.js，无运行时 CDN 依赖。修改依赖后运行 npm ci 和 node scripts/bundle-cloud.cjs。

测试：npm test。导入、URL 去重、搜索、危险 URL 拒绝，以及 B 站跨子域 / 知乎专栏 / YouTube 页面链接采集均有自动测试。

推送 main 后，GitHub Actions 自动检查并发布 dist/ 到 GitHub Pages。

## 云端架构

数据库结构见 supabase/migrations/，library_entries 使用 (user_id,url) 主键、RLS 和删除标记。客户端本地记录待同步操作，成功确认后才移除；同步过程中出现的新编辑保留在队列。跨设备同一条笔记同时编辑采用最后一次成功写入；建议避免多端同时编辑同一条。重新收藏重复链接保留已有笔记，删除后再次收藏可恢复。客户端使用公开 publishable key；不要在 dist 或扩展中放 service_role / secret key。

项目部署时同时更新网站与扩展中的 cloud-config.js。测试覆盖离线重试、上传中编辑、删除标记、重复链接和登录链接校验；数据库已在回滚事务中验证跨账号读写隔离。

## 本机文件整理

本机相关文件统一位于 F:\Apps\shiguang：

- collector/：浏览器扩展，Chrome 加载此目录。
- dist/：网站网页。
- tools/：本机发布工具、下载包和操作截图，仅本机保留。
- archives/：旧版压缩包，仅本机保留。

tools/、signing/、archives/ 已加入 .gitignore，不会随代码上传 GitHub。

收藏分类支持下拉选择、输入筛选及新建，可多选。更新扩展后先刷新拾光网站，让已有分类同步到扩展，再使用空格＋S 收藏。分类和原因均为选填。
## 封面服务

supabase/functions/link-preview，要求用户 JWT，另外通过 Auth 验证用户，不转发用户凭据到来源网站；不修改数据库权限。登录后的知识库会为任意 https 网站自动补全公开封面：优先读取页面的 OG / Twitter 图片，其次使用页面声明的 apple-touch-icon / icon；B站、知乎、YouTube 等已知平台另有专门解析（合集每集、oEmbed 标题等），YouTube 使用原视频缩略图。平台拒绝访问、站点没有可用的公开图片或封面失效时回退装饰封面，不影响保存和搜索。

安全边界：抓取仅限 https 且不带访问凭据；私网与保留地址（127.x、10.x、192.168.x、169.254.x 云元数据等）直接拒绝，每个重定向跳转都重新校验；公网域名需经 DNS-over-HTTPS 解析确认全部指向公网地址才发起抓取，解析失败按拒绝处理；逐用户限流 60 次/分钟，结果缓存 24 小时，单次响应上限 1.5 MB，不执行对方页面脚本、不携带 Cookie。
